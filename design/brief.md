# 星汐产品设计简报

## 产品目标

把用户喜欢的星汐星空审美延续到独立本机工作台：项目 LLM Wiki 与陪伴记忆是两个明确的空间类型，同一套星图、星册、星历、星工坊服务于不同内容。

## 目标用户与核心任务

个人开发者/知识工作者。核心任务是将项目资料导入、整理、核对证据、确认、检索；在工作之外保留一段自然的陪伴对话。首要流程：收下资料 → 工坊手动/模型整理 → 星册确认 → 星图探索 → 对话使用。

## 页面范围与目标设备

左侧空间与导航；星图的关系画布；星册卡片和阅读面板；星历最近变化；工坊的来源、模型、人格、MCP；带会话列表的对话页。桌面 1440×900，手机 390×844。手机把导航放到底部，空间切换保留在顶部，详情为浮层。

## 技术约束

本机 Node HTTP + SQLite + React/Vite，静态构建可离线加载，无外部字体、图片或遥测。Key 只在服务端保存。MCP 与 Web 使用同一服务；工作/陪伴数据不跨空间检索。原文不可变、候选需确认、修订可追溯。首版不接入 QQ/B 站。

## 内容密度

默认示例图 12 个节点、12 条真实语义关系；示例星册可读完整标题、三行正文和来源数量。星图不使用装饰性虚假连接，筛选后只显示可见节点之间的关系。详情展示正文、出处、相关条目及修订。空空间同样提供明确入口。

## 可访问性

实际按钮、输入标签、键盘焦点、模态框 Escape 与 Tab 循环。星图每颗星都是可聚焦的 DOM 按钮，星册提供等价列表。颜色之外保留类型文字；正文使用较浅灰，次级信息弱化。无自动旋转，支持 reduced-motion。手机保持页面可纵向滚动，不允许横向溢出。

## 素材权利边界

星点纹理及投影函数派生自 Yuuyuko-uu/dsh-xingxi，保留原作者与自定义许可。新布局、服务和数据模型在星汐内实现，整个发行版遵循上游许可。Lucide 图标来自 npm 依赖。没有引入角色插画或其他站点图片；无需角色素材包。

## 成功标准

真实新建空间、导入资料、手动整理、确认、查原文、编辑留历史完整可用；MCP 真实 stdio 握手与命名空间校验通过；桌面与手机无主要布局遮挡；模型未配置时说明原因、不产生假回复。
