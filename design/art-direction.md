# 视觉方向

用户已经明确选择星汐的星空审美。本轮不再打断用户做风格投票；比较以下方向后沿用已确认方向。

| 方向             | 视觉与结构                                           | 判断                                           |
| ---------------- | ---------------------------------------------------- | ---------------------------------------------- |
| 静夜星图（选定） | 蓝黑底、低对比面板、淡紫主操作、青绿决策、星光与细线 | 延续用户审美，适合长时间工作和晚间闲聊         |
| 纸页星册         | 暖白阅读面、墨蓝文字、图谱仅作为附页                 | 阅读有优势，但偏离用户特别喜欢的星空质感       |
| 角色工作室       | 大幅角色、粉紫面板、强调陪伴                         | 容易压过工作资料，角色素材与人格也未由用户指定 |

## 最终执行

- 颜色：深蓝灰 `#0e1422` 主画布；`#151d2d` 内容面；`#c5b9ed` 主操作。图谱不同类型用淡紫/薄荷/暖金/粉色，但始终有文字标签。
- 排版：系统无衬线用于信息，少量宋体用于侧栏短句。标题 29px，阅读正文 13px/1.9；元信息弱化。手机缩为单列，长来源允许滚动。
- 布局：230px 侧栏 + 主区；星图详情 290px 侧面板。星册采用卡片，工坊两列功能区。手机底部 5 项导航，顶部保留空间选择。
- 角色密度：0。不引入未确认的人物形象，以简洁星芒作为 AI 身份符号。
- 动效：没有自动旋转或背景闪烁；仅轻微 hover 和必要 loading。reduced-motion 下禁用动画。
- 内容边界：示例资料明确虚构，不将用户过往兴趣、QQ 信息或账号带入。

## 对应实现

`src/tokens.css` 是运行时 CSS 变量，`design/tokens.json` 记录同一语义值。`src/star-renderer.js` 标注上游派生；`Graph.jsx` 使用投影与星点纹理，叠加可聚焦的实际节点按钮。
